# 쎈스 글리프 — 손글씨 폰트 작업실

손글씨 입력부터 자모 확인·한글 조합·OTF 폰트 다운로드까지 이어지는 로컬 우선 웹앱입니다. 글자별 원본 중심선, 필압, 기울기, 시각과 브러시 파라미터를 벡터 데이터로 보관합니다.

**브러시 → 견본 → 글자 쓰기 → 자모 나누기 → 폰트 완성** 순으로 진행합니다. [단계별 이용 안내](JOURNEY.md)를 참고하세요.

- 목표는 쓴 손글씨 그대로의 폰트입니다. 악필을 단정하게 다듬는 정돈 기능은 0%(꺼짐)가 기본이며 강도와 항목을 조절할 수 있습니다: [손글씨 정돈](CORRECTION.md)
- 쓴 글자는 모두 손글씨로 내보내고, 쓰지 않은 글자는 견본 글꼴 모양으로 채웁니다(내보낼 때 경고 표시). 결제 단계는 없고, 다운로드할 때 임시 다운로드 코드를 입력합니다.
- 다이아몬드 안에 쓴 글씨의 출력 크기·좌우 여백 보정: [폰트 크기 보정](NORMALIZATION.md)
- 이전 화면 기준의 기록: [사용성 개선](USABILITY.md), [확인 목록](REVIEW.md)

## 실행

Node.js 22 이상에서 프로젝트 폴더를 열고 실행하세요.

```powershell
npm ci
npm run dev
```

정적 배포 및 오프라인 확인:

```powershell
npm run build
npm start
```

http://127.0.0.1:3000 에서 열립니다. 정적 결과물은 out/입니다. 서비스 워커가 처음 로컬 리소스를 저장한 뒤에는 네트워크를 끊고 새로고침해도 동작합니다. 서비스 워커는 HTTPS 또는 localhost에서 동작합니다. 배포 시 out/ 전체를 사이트 루트에 올리세요. 개발 모드는 오프라인 캐시 대상이 아닙니다.

## 배포 (GitHub Pages)

https://osense.github.io/SenseGlyph/ 에서 동작합니다. 다음 명령으로 `/SenseGlyph` 하위 경로용 정적 사이트를 만들고 `gh-pages` 브랜치에 올립니다.

```powershell
npm run deploy
```

다른 하위 경로에 올릴 때는 `NEXT_PUBLIC_BASE_PATH`로 경로를 지정해 빌드하세요. 글꼴·폰트 생성 워커·오프라인 캐시 경로가 함께 바뀝니다.

## 화면 기준

태블릿이 주 사용 환경입니다. 글자 쓰기 단계는 한 화면 앱 형태로, 남는 높이를 모두 쓰기 칸에 줍니다(iPad 가로 1180×820에서 약 550px, 세로 820×1180에서 약 680px).

- 가로: 도구 레일 | 쓰기 칸 | 다음·확인 패널, 아래 글자 모음
- 세로: 도구 줄 + 큰 쓰기 칸 + 다음·확인 줄, 아래 글자 모음
- 휴대폰: 한 열로 쌓고 페이지를 스크롤합니다.

규칙은 [app/studio.css](app/studio.css)에 있습니다. 굵기·지우개·쓰기 칸 크기 같은 자주 바꾸지 않는 설정은 "도구 설정" 시트로 모았습니다.

## 사용

- 브러시·굵기를 고르고 연습한 다음, 견본 일곱 종을 같은 문장으로 비교합니다. 연습 칸은 폰트에 들어가지 않습니다.
- 쓰기 단계에서 아래 글자 모음 또는 이전/다음으로 이동합니다. 기본 글자(한글 138·숫자·기호·영문 232자)를 먼저 쓰고, 특수문자(낱자모·문장 기호·특수 기호)는 따로 모았고, 쓰지 않으면 견본 글꼴로 채웁니다.
- 점선 밖으로 나간 획도 저장합니다. 알림만 보여주고, 폰트에는 비율을 유지한 채 칸 안으로 줄여 넣습니다.
- 따라 쓰기 / 보고 쓰기를 전환할 수 있습니다. 격자의 세로·가로·다이아몬드·크기 가이드는 각각 설정할 수 있습니다.
- 첫 펜 입력은 펜 전용 입력을 자동으로 켭니다. 손가락으로 쓰려면 설정에서 해제하세요. 마우스는 설정에서 허용할 수 있습니다.
- 펜 끝의 지우개 또는 측면 버튼은 해당 제스처 동안 지우개로 작동합니다.
- P: 펜, E: 지우개, ← / →: 글자 이동, Ctrl/⌘+Z: 취소, Ctrl/⌘+Shift+Z: 다시 실행. 입력 필드를 조작하는 동안에는 앱 단축키가 개입하지 않습니다.
- 자모 나누기의 초·중·종성 판정 영역은 견본 단계에서 고른 글꼴의 해당 글자를 실제로 나눠서 만듭니다. 글꼴의 외곽선 조각을 단위로 같은 글꼴의 낱자모 조각 수, 받침 없는 음절 모양(곤 → 고)과 비교하며 자릅니다. 손글씨 글꼴처럼 자모가 붙은 경우에만 가장 얇은 곳을 자릅니다. 화면의 진한 색은 견본 글자의 자모 획이고 옅은 색은 그 자모로 판정되는 범위입니다. 글꼴 파일이 바뀌면 `python scripts/build-reference-regions.py`로 data/reference-regions.json을 다시 만드세요.
- 획 확정·삭제·설정 변경 후 500ms 디바운스로 IndexedDB에 저장합니다. 저장 상태를 상단에서 확인하세요. 페이지를 떠나거나 숨길 때도 저장을 시도합니다.
- 브라우저 데이터를 지우면 저장한 작업도 지워집니다. 설정의 JSON 내보내기로 백업하세요. JSON 가져오기는 새로운 ID의 프로젝트로 복원하며, 기존 프로젝트 레코드는 삭제하지 않습니다.

## 펜과 입력 크기

- 납작펜은 겹치는 구간을 같은 방향의 여러 면으로 채워, 한 획 안에서 되돌아 쓰거나 교차해도 잉크가 사라지지 않습니다. 화면·자모 편집·OTF에 같은 외곽선을 사용합니다.
- 픽셀펜의 입자 크기는 4~40 em으로 조절합니다. 입자는 저장 좌표 격자에 맞춰 결정되므로 화면 크기나 다시 열기에 따라 무작위로 바뀌지 않습니다. 픽셀펜은 시작 브러시 선택과 쓰기 도구에서 모두 사용할 수 있습니다.
- 쓰기 메뉴에서 입력 칸을 180~900px로 조절하거나 자동 맞춤으로 되돌릴 수 있습니다. 큰 칸은 입력 영역 안에서 스크롤하며, 크기 변경은 원본 1000 em 좌표와 폰트 크기를 바꾸지 않습니다. 크기는 프로젝트에 저장됩니다.
- 자모 나누기의 글자 슬라이드는 편집기 아래에, 초·중·종성 설명은 제목 오른쪽에 있습니다. 좌우 이동 버튼은 편집 면 바로 옆에 붙어 있습니다.
- 기존 프로젝트·백업에는 픽셀펜 기본 설정을 추가해 읽습니다. 이미 쓴 납작펜 획도 수정된 외곽선으로 다시 표시되며, 설치한 글꼴을 바꾸려면 OTF를 다시 생성해야 합니다.

## 검증

```powershell
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm start
# 별도 터미널
npm run test:flow
```

`test:flow`는 현재 화면 흐름을 확인합니다. `test:journey`·`test:workspace`·`test:usability` 등 나머지 브라우저 스크립트는 이전 화면 기준으로 작성되어 선택자 갱신이 필요합니다.

자동 검증 범위와 실제 확인 결과는 [IMPLEMENTATION.md](IMPLEMENTATION.md)에 정리했습니다. 브라우저 검증은 격리된 테스트 브라우저에만 데이터를 쓰며 사용자 작업에는 영향을 주지 않습니다.

## 폴더

- app/: 화면, 레이아웃, 반응형 스타일
- components/: 입력 캔버스, 브러시·견본·썸네일
- lib/: 모델, 좌표/지우개, 한글 분해, 브러시, 상태, IndexedDB 및 JSON 검증
- data/charset.ts: 명세의 294자와 카테고리
- config/metrics.ts: UPM과 영문 기준선
- public/fonts/: 현대 한글 전체 Noto Sans KR와 SIL OFL 라이선스
- scripts/: 정적 서버, 오프라인 캐시 생성, 브라우저 통합 검증
- artifacts/: 실제 브라우저 화면 및 검증 결과

## 명세 해석

- SPEC의 M3에는 canvas 3장이라고 되어 있으나 5.1은 라이브 레이어 분리를 요구합니다. 격자 / 견본 / 확정 잉크 / 진행 중 획의 4장으로 분리했습니다.
- 마우스 입력은 바로 체험할 수 있도록 기본 허용합니다. 펜 전용 모드가 켜지면 마우스 허용 여부와 관계없이 펜만 입력받습니다.
- 선택 카테고리와 화면 테마는 UI 선호로 localStorage에 저장합니다. 명세의 ProjectSettings 모델은 그대로 유지하며 이 두 UI 선호는 프로젝트 JSON에 포함하지 않습니다.
- 후속 요청에 따라 자모 분리·수동 보정·11,172자 조합·Web Worker OTF 생성·실제 FontFace 미리보기·다운로드를 추가했습니다. 기존 프로젝트는 그대로 열리며, 선택 필드 fontPreparation에 제작 설정과 보정을 저장합니다.
